## Breast Cancer Classification — Practical 2

This project demonstrates Git version control for a machine-learning classification project using the Wisconsin Diagnostic Breast Cancer dataset built into scikit-learn.

### Run

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
py breast_cancer_classification.py
```

The script trains a decision tree classifier and prints the dataset shape, train/test sample counts, accuracy, and class names.
